# KCP 결제 연동 가이드

## 1. KCP 결제 필수 입력 필드

### 기본 정보 (필수)

- `site_cd`: 사이트 코드 (KCP에서 발급받은 가맹점 코드)
- `site_name`: 사이트명 (예: "TEST SITE")
- `ordr_idxx`: 주문번호 (최대 40자, 고유값)
- `good_name`: 상품명
- `good_mny`: 결제금액 (숫자만, 콤마 제외, 최대 9자리)

### 구매자 정보 (필수)

- `buyr_name`: 주문자명
- `buyr_tel2`: 휴대폰번호 (필수)
- `buyr_mail`: 이메일 주소

### 구매자 정보 (선택)

- `buyr_tel1`: 전화번호

### 결제 수단 설정

- `pay_method`: 결제수단 코드
  - 신용카드: "100000000000"
  - 계좌이체: "010000000000"
  - 가상계좌: "001000000000"
  - 포인트: "000100000000"
  - 휴대폰: "000010000000"
  - 상품권: "000000001000"
  - 복합결제: "111000000000" (신용카드+계좌이체+가상계좌)

### KCP 응답 필드 (읽기 전용)

- `res_cd`: 응답코드 ("0000" = 성공, 기타 = 실패)
- `res_msg`: 응답메시지
- `ordr_chk`: 주문정보 검증값 (보안 검증용)
- `enc_info`: 암호화 정보
- `enc_data`: 암호화 데이터
- `ret_pay_method`: 실제 사용된 결제수단
- `tran_cd`: 거래코드
- `use_pay_method`: 사용된 결제수단 상세

### 현금영수증 관련 (선택)

- `cash_yn`: 현금영수증 발급 여부
- `cash_tr_code`: 현금영수증 거래코드
- `cash_id_info`: 현금영수증 발급번호

## 2. 결제 플로우

### 2.1 결제 요청

1. 사용자 입력 데이터 수집
2. 폼 검증 (필수 필드, 형식 검증)
3. KCP 결제창 호출 (`KCP_Pay_Execute()`)
4. 사용자가 결제창에서 결제 진행

### 2.2 결제 완료 콜백

1. `m_Completepayment()` 함수 자동 호출
2. `res_cd` 값 확인 ("0000" = 성공)
3. 성공 시 결제 승인 요청
4. 실패 시 에러 메시지 표시

### 2.3 결제 승인

1. KCP에서 받은 데이터로 결제 승인 요청
2. 서버에서 최종 결제 처리
3. 결제 완료 페이지로 이동

## 3. 보안 고려사항

### 3.1 주문정보 검증

- `ordr_chk` 값으로 주문정보 무결성 검증
- 서버에서 `ordr_idxx`와 `good_mny` 재검증 필수

### 3.2 필수 검증 항목

```javascript
// 결제 완료 후 반드시 검증해야 할 항목
if (frm.res_cd.value == "0000") {
  // 1. 주문번호 검증
  // 2. 결제금액 검증
  // 3. 상품명 검증
  // 4. 구매자 정보 검증
}
```

## 4. 개발 환경 설정

### 4.1 KCP 스크립트 로드

```html
<!-- 개발 환경 -->
<script src="https://testpay.kcp.co.kr/plugin/payplus_web.jsp"></script>

<!-- 운영 환경 -->
<script src="https://pay.kcp.co.kr/plugin/payplus_web.jsp"></script>
```

### 4.2 필수 함수 정의

```javascript
// 결제 완료 콜백 함수 (함수명 고정)
function m_Completepayment(FormOrJson, closeEvent) {
  // 결제 완료 처리 로직
}

// 결제창 호출 함수
function jsf__pay(form) {
  try {
    KCP_Pay_Execute(form);
  } catch (e) {
    // IE에서 결제 정상종료시 throw로 스크립트 종료
  }
}
```

## 6. 테스트 데이터

### 6.1 테스트용 가맹점 정보

- 사이트코드: "T0000"
- 사이트명: "TEST SITE"

### 6.2 테스트용 주문 정보

- 주문번호: "TEST" + 현재시간
- 상품명: "테스트 상품"
- 금액: 1000원 이상 (테스트용)

## 7. 주의사항

1. **금액 설정**: `good_mny`는 반드시 숫자만 입력 (콤마 제외)
2. **주문번호**: 40자 이내, 고유값이어야 함
3. **함수명**: `m_Completepayment` 함수명은 절대 변경 금지
4. **스크립트 순서**: `m_Completepayment` 함수는 payplus.js보다 먼저 선언
5. **검증 필수**: 결제 완료 후 반드시 주문정보 재검증
