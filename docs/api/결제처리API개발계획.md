# 요구사항

- 첨부로 넣은 프론트 컨트롤러단 (/ /path)를 실제로 유용한 결제 처리 API 호출 로직으로 바꾸는 것이 목표.
- 원하는 로직

  - 결제 처리 rest API를 호출한다.
  - 해당 API의 응답을 이용해서 원래 리턴하려던 것을 동일하게 리턴하여 페이지 수정사항이 없도록 조치.

- 위에서 언급한 결제 처리 rest API
  - dsSnsPlatform2 프로젝트의 board 모듈에 작업 진행
    - path : /order/pay-process
    - 로직 :
      - 주문의 유효성을 확인.
      - 주문을 결제 요청중 상태로 변경
      - 토스의 결제 승인 API(기존 코드 참조)를 호출
      - 성공일 경우
        - 여기는 성공했을 때 로직입니다 를 log로 출력한다.
        - 그리고 해당 부분에 TODO 주석을 (여기에 본래 넣고 싶은 성공 비즈니스 로직 추가.) 라고 남긴다.
      - 실패일 경우
        - 여기는 실패 했을 때 로직입니다를 log로 출력한다.
        - 그리고 해당 부분에 TODO 주석을 (여기에 본래 넣고 싶은 실패 비즈니스 로직 추가.) 라고 남긴다.
      - 토스의 결제 승인 API의 응답이 오지 않고, 타임아웃이 일어 난경우
        - 여기는 타임아웃시 로직입니다를 log로 출력한다.
        - 그리고 해당 부분에 TODO 주석을 (여기에 본래 넣고 싶은 타임아웃시 비즈니스 로직 추가.) 라고 남긴다.
      - 적절한 리턴을 반환한다.
